四、启动、导出和检查命令
在代码目录执行：
  node --version
  npm ci
  npm run dev
默认开发地址由vite.config.ts指定为 http://127.0.0.1:5190/ 。

要求Node.js >=24。审计时普通shell的node是v20.20.0，npm为10.8.2，不能直接用这个node宣称构建环境满足要求。
package.json锁定依赖：three 0.186.1、@types/three 0.186.0、playwright 1.64.1、typescript 7.0.2、vite 8.3.5、vitest 5.0.5。package-lock.json应随源码保留，使用npm ci。

常用命令：
  npm run build
  npm run check
  npm exec vitest -- run tests/battle-start.test.ts tests/battle-pause.test.ts --maxWorkers=4
  npm run package:battle
package:battle导出delivery/独立战斗场景.html；.gitignore忽略delivery，所以公开交接包若要同时携带离线版，应单独纳入发布文件或显式保留，不能以git add默认结果当作已经上传。

已有浏览器QA脚本：
  node tools/battle-smoke.mjs
  node tools/battle-outcome.mjs
两者硬编码macOS Chrome路径。换电脑须先调整副本或统一传入浏览器路径；skill-web-game-client.mjs支持BATTLE_CHROME_PATH，不能误认为其他脚本也支持同一变量。
tools/lib/harness.mjs使用TAPTAP_STUDIO_DIR或系统临时目录；带有旧Windows目录的历史fallback，不应执行旧调度流程。
npm run data:import / data:check依赖外部原始dump，默认D:/TAPTAPGAME_codex/reference/dump；它们不是新机器启动必需步骤。不要为运行游戏而重新抓取、覆盖已生成数据。
部分内容roundtrip/source测试在原dump不存在时会跳过；测试全绿不代表这些外部来源核对已经执行。
GDD build_config.py会重建初始配置，人工调过JSON后不要随意运行；其旧两层基线也不能用于覆盖100怪专项。
