# 页面契约与状态 · 手机迭代 02

日期：2026-10-29。共12页。所有尺寸、字色与组件引用《项目UI宪法.md》；功能和数据边界引用《需求与数据边界.txt》。本文件描述设计要求与候选状态，不宣称已接入游戏逻辑。

## 1. 共用信息优先级

| 级别 | 内容 | 处理 |
|---|---|---|
| S0 | 实时生命/体力/腐化、真实不可逆后果、必要错误反馈 | 清晰可见，不能被插画或边框遮挡 |
| S1 | 当前任务、选中对象、主要动作及其成本/去向 | 第一阅读层；未知成本不可伪造 |
| S2 | 物品机制、角色属性、比较依据 | 与对象相邻；长内容滚动 |
| S3 | 收藏查看、完整细节、低频说明 | 按需展开，避免永久平铺 |
| S4 | 场景、商人、纹理、材质 | 退后，不能与S0–S2争抢 |

金币4、生命180/180、体力100/100、腐化0/100为已核对旧版样本，只用于操作前视觉展示，不是新平衡或交易后状态。所有价格与成长费用未知，因此本轮不包含完整的交易决策验证。

## 2. 十二页契约

### 01 · 战斗／装备栏位

契约：玩家处于战斗时，界面帮助其看清战场和自身状态，同时查看已装备物品，避免把装备查看误当成整理。

- 入口/所在：进入战斗或关闭查看面板；装备栏位页签选中。
- 主要任务：观察敌我并进行战场操作。触控瞄准/发射的具体手势需与最终游戏输入适配核对；不额外添加自动战斗或攻击技能按钮。
- S0生命/体力/腐化；S1战场与选中装备；S2必要机制；S3属性与图鉴入口；S4边缘材质。
- 路径：战斗→查看装备→打开详情→关闭回到同一战场。
- 状态/恢复：装备可点选查看；上下排序、装卸与培养在战斗中不可执行，等待发射仍保持限制。误触详情可用大关闭控件返回，不触发发射或移动物品。

### 02 · 战斗／英雄属性与天赋

契约：玩家在战斗中查看当前角色时，能同时理解人物属性与角色天赋，随后直接返回战场。

- 入口：英雄属性全局页签；左区加中区600宽展开，人物属性在左，角色天赋在右，右包保留。
- 主要动作：完成查看后返回装备栏位；不增加属性/天赋二选一子页签。
- S0当前战斗状态；S1人物属性与选中天赋；S2效果说明；S3其余节点；S4低对比角色轮廓。
- 路径：打开英雄属性→选择节点→阅读效果→切回装备栏位。
- 状态/恢复：只读，不得出现可执行解锁/升级。节点外观如展示已解锁/未解锁，只是图外标注的状态样例，不能据此认定真实已学。180生命由现有装备附加效果支持，不归因于已学习体质。

### 03 · 战斗／装备图鉴

契约：玩家查阅装备收藏时，能区分已知物品和目录资料，阅读对应品质的机制，随后返回战斗。

- 入口：装备图鉴全局页签。
- 主要任务：选择条目并阅读；不提供购买、装备、升级或天赋内容。
- S1当前条目名称/品质版本；S2机制；S3其他收藏；S4封面纹理。
- 路径：打开图鉴→点选物品→滚动完整说明→返回装备栏位。
- 状态/恢复：已收集示例仅沿用已装备三件，不编总收藏数。青铜目录与当前实例必须明确区分，不能合并效果。无结果时说明列表为空并保留返回，不凭空生成未知物品。

### 04 · 营地／冒险准备

契约：玩家回到营地后，能整理携带物、检查成长入口和选择地牢层，然后明确出发。

- 入口：返回营地；左装备、中央整备、右背包。
- 唯一主要动作：出发进入已选层。保险箱、天赋培养和层选择为次要入口。
- S1已选层、携带装备和出发；S2保险箱/天赋入口；S3详细状态；S4营地氛围。
- 路径：回营→整理/存取→必要时培养→选层→出发。
- 状态/恢复：非战斗阶段才可整理。没有合法层时不出发，需给真实原因；层进度样例不等同于存档。不添加一键强化、合成、锻造或加工。

### 05 · 营地／天赋解锁

契约：玩家在营地选择一个尚未解锁天赋时，能看到真实效果与解锁资源类型，准备作出培养选择。

- 入口：营地天赋培养或英雄属性页；仍为左属性右天赋同屏。
- 主要动作：解锁天赋；资源类型为技能点。
- S1选中节点/效果；S2解锁资源；S3其他节点；S4树状连接的低对比视觉。
- 路径：进入英雄页→选择待解锁节点→阅读→满足真实条件后才可提交→成功后显示新状态。
- 边界：具体费用、技能点余额、前置依赖、最大等级未定，不写2点、1/8、免费或不足等判断。当前图只演示解锁状态，不执行培养。节点连接不能被宣称已确定的成长前置。

### 06 · 营地／天赋升级

契约：玩家在营地查看已解锁天赋时，能区分当前效果与升级动作，避免误把升级当成再次解锁。

- 入口：同一英雄页的已解锁节点样例。
- 主要动作：升级天赋；资源类型为金币。
- S1节点名/当前效果/升级；S2资源类型；S3其余节点。
- 路径：选择已解锁节点→检查效果与真实费用→满足条件再升级→显示成功及实际变化。
- 边界：本轮没有金币费用、等级、下级效果或最大值，全部省略。不能让12.5%凭空跳成25%，也不能把旧金币4用于判断买得起。成功/失败外观是生产状态要求，不是本轮已发生的事件。

### 07 · 营地／保险箱存取

契约：玩家整理安全存储时，能分清保险箱与随身背包，并把选中物品移动到正确目的地。

- 入口：营地保险箱。中央安全存储与右侧随身包是不同容器。
- 当前页主要动作：取出到背包。只有选中随身物品后，才进入存入动作状态。
- S1选中物品、源/目的容器与操作；S2死亡保护说明；S3其他物品；S4保险箱材质。
- 样例：唯一当前灵魂香菇在箱内，左装备对应位置为空，右包为空，取出前不得同时出现多个实例。
- 路径：打开→选中→查看去向→执行存取→两容器一致更新→返回营地。
- 状态/恢复：目的空间不足时源物品保留，不吞物、不复制。没有选择时动作不可执行。箱内物品死亡不丢失；不增加保险费、利息或付费扩容。

### 08 · 营地／地牢选择

契约：玩家选择目标地牢层时，能区分可重打、可进入与未解锁层，并回到整备后出发。

- 入口：营地当前层入口；直线层级列表，不画分叉路线地图。
- 主要动作：选择当前可进入层；最终出发沿用营地统一动作。
- S1当前选中层与可进入状态；S2已通关/未解锁；S3其他层。
- 样例：第1层已通关可重打、第2层选中、第3层锁定，仅供状态展示，不是存档。
- 路径：打开→选择合法层→返回营地确认当前选择→出发。
- 状态/恢复：锁定状态有锁与文本，不仅变灰；具体解锁条件、奖励、入场费、星级和计时未定，不发明。退出不改变装备与金币。

### 09 · 商店／购买详情

契约：玩家在商店选择商品时，能看到商品版本、效果与购买去向，并在真实报价齐备后决定是否购买。

- 入口：战利品之后的商店阶段。左136商人剪影，中448商品与详情，右136随身包；装备网格暂收，顶部装备入口保留。
- 主要动作：购买装备。购买/出售是服务内模式，不增加全局页签。
- S1选中商品与购买；S2主要效果、去向、真实报价（本轮缺失）；S3其他商品；S4商人插画。
- 样例：商人拥有青铜淬毒利刃（15剧毒、30%会心、8次剧毒后1层易伤）；与已装备品质代码2利刃是不同实例。交易前右包为空。
- 路径要求：选择→阅读/比较→校验报价和空间→购买→余额与库存同步更新。
- 恢复要求：失败不扣钱、不丢物；空间不足指出目的容器。当前报价未知，不能显示0、旧回收值、折扣或“金币不足”，不能称为完整交易验证。

### 10 · 商店／出售详情

契约：玩家选择随身物品出售时，能确认对象与后果，避免点选即出售或把已装备物品重复卖出。

- 主要动作：出售选中物品；售价必须由真实商店数据提供，本轮省略。
- S1明确对象、出售动作与物品失去的结果；S2机制与真实回收报价（缺失）；S3其他可售物品。
- 样例：唯一当前凝血毒剂已先从装备移到右包第一行，左对应槽空；香菇和利刃仍装备。商店商品区不能复制此瓶。
- 路径：切出售→选中右包物品→查看→主动出售→成功后移除并更新金币。
- 恢复：取消只取消选择，失败保留原物；不增加买回、出售全部或自动分解。交易前不得显示“金币5”或成功提示。是否需要强确认取决于最终不可撤销规则，未定前不擅加连续确认弹窗。

### 11 · 战利品／宝箱领取

契约：玩家打完一波战斗后，能识别待领取物品并将其放入随身包，再进入后续流程。

- 主要动作：领取到背包；不以升级、刷新、下一层或全部装备代替领取。
- S1奖励对象与领取；S2物品机制和目的容器；S3其他奖励；S4宝箱氛围。
- 样例：待领是另一件青铜灵魂香菇（每次搜寻增加2价值、最多8）；已装备香菇仍为当前4/16实例，右包领取前为空。
- 路径：出现奖励→选中查看→领取→目的包出现同一奖励实例→后续商店流程。
- 恢复：背包满时奖励不能被吞掉或自动分解。关闭后未领取奖励的保留/丢弃规则尚未定，不能承诺无限保存，也不能自创惩罚。

### 12 · 战斗／装备详情

契约：玩家点开当前装备时，能阅读完整效果和充能状态，关闭后继续同一战斗。

- 入口：点选已装备品质代码2淬毒利刃。
- 主要动作：关闭详情返回；没有购买/出售/升级/装卸动作。
- S1物品名称、当前主要效果与已装备状态；S2完整机制/0至100充能；S3来源与目录区别仅在图外解释。
- 当前效果：下3次攻击在3回合内造成30剧毒；敌人受到8次剧毒后获得2层易伤；现有附加效果为提升20%生命上限；充能0/100。
- 路径：选中→阅读/滚动→关闭。
- 恢复：关闭不移动物品、不发射。详情大图标与装备栏是同一实例的两处展示，不是新增第二件。

## 3. 组件状态矩阵

| 状态 | 表现与说明 | 防错要求 |
|---|---|---|
| 默认 | 稳定轮廓，名称与用途明确 | 静态标签不能长得像按钮 |
| 按下 | 表面明度/压入变化，文字不位移漂移 | 保留至少48热区；反馈不阻塞后续输入 |
| 选中 | 底色加标记/下划线，并有语义状态 | 不仅改变颜色；点选不立即移动或交易 |
| 禁用 | 表面弱化但原因仍清楚 | 只能依据已知规则，如战斗不可整理；未知价格不能推断余额不足 |
| 锁定 | 锁图形和“未解锁”等文本 | 未定具体条件不编造；锁定项不能进入或消耗资源 |
| 空 | 弱空槽/明确空容器 | 不加装饰物伪装已有物品，不自动占用空间 |
| 长文/溢出 | 原字号换行，独立滚动区域，提示还能滚动 | 不截断关键效果；不缩小到12塞入主要信息 |
| 处理中 | 仅真实请求时显示短状态，提交动作暂不可重复 | 不提前扣资源、不提前显示成功 |
| 成功 | 对象、去向、实际变化可见 | 金钱/物品/节点同步更新；无真实状态变更不能展示成功 |
| 错误 | 指出失败事项，并提供返回/重试或腾挪空间路径 | 保留提交前状态，不能吞物、重复付费或假装完成 |

## 4. 三项跨页不变量

1. 所有权：每件物品的实际实例只在一个容器中。详情缩略图是视图，商店目录商品是另一个实例，两者必须语义清楚。
2. 版本：当前利刃30/2/20%与青铜利刃15/1/30%会心不混用；当前香菇4/16与青铜香菇2/8不混用；毒剂与香菇不凭共有字段画充能条。
3. 事务：成功之前状态不变，失败保持原状，重复点击不重复提交；未知报价和成长数据不得靠UI猜测补齐。

## 5. 本轮可核验范围与保留缺口

可核验：12页结构、文本/数值来源、字体档位、布局尺寸、热区测量、容器归属、长文本、空/锁定/战斗禁用外观。

明确缺失：新经济报价与成长配置，因此购买/出售/解锁/升级的完整决策路径不能验收；真实交易成功/错误仅列设计要求，不等于已实现。

还需真实手机与新用户检验：实际文字可读性、手指遮挡、误触、横屏安全区、系统手势、最大字号、首次正确操作和退出恢复。浏览器截图与作者自测不替代这些证据。
