2. 308件后续编辑母版
pixel-master-map.json直接映射到已有pixels/256/ID.png，不再额外复制图像。
映射记录每件名称、ID、分类、占格，以及128/256两档的尺寸、字节数、文件SHA256和解码像素SHA256。
需要改图时以256档为像素底稿，先另存工作副本，再用支持透明和最近邻缩放的像素编辑器修改。
保留原画布尺寸、占格比例、留白和稳定ID；两个分辨率各自检查，不自动覆写已认可锚点。
编辑之后要重新目视确认、更新相应回执与哈希，并通过索引、PNG和图集检查。
现有256图不能精确反推出高分辨率原稿；将256缩成128也不保证等于最初独立转换的128档。
因此两档发布PNG都保留，不把“像素编辑母版”说成可精确恢复全部原稿的无损源文件。

3. 高分辨率原稿边界
原先308张高分辨率母图共498,562,878字节，已移出公开交接副本。
原始母图只在原电脑的图标工坊/editions/v6-handdrawn-production/mothers/留存，原制作源目录未改。
本机发布索引记载原稿位置；不再为交接额外复制约499MB归档。
QA淘汰记录中的7张高分辨率源图也已在核对原工坊同名SHA后移出交接副本，共12,329,117字节；
它们仍在原工坊qa/rejected/，公开包保留像素尺寸淘汰稿和检查JSON。
公开完整包、精简包与GitHub Release都不再提供高分辨率母图附件。
历史manifest的mother路径及receipts里的motherSha256用于追溯，不意味着公开包带有这些文件。
qa/handoff-rebuild-validation.json保存移出之前从高分辨率原图重现616张PNG的历史检查。
该记录不能被解释成当前公开包在没有原稿时仍能精确重建两档PNG。

4. 压缩检查
616张发布PNG已经是限色索引PNG，只含IHDR、PLTE、tRNS、IDAT、IEND标准块。
用当前Pillow 12.2.0在内存以optimize=True、compress_level=9重新无损保存，616张字节完全相同，
这一方法没有额外压缩收益。因此保留原文件，避免无意义地改动冻结哈希及QA链。
压缩检查见qa/pixel-compression-check.json。减小公开包的主要措施是移除约499MB高分辨率原稿。

5. 原制作流程仍保留
先保留名称、功能、占格和未知项，再写逐件提示词。
原流程用已认可的三件样稿/风格板和《风暴怕死队》官方裁图，约束墨线、色块、形体与阴影。
通过内置image_gen逐件生成透明高分辨率母图，再做算法像素化。
转换为预乘透明等比Lanczos缩放、轻微锐化、无抖动Median-cut限色、alpha阈值128。
128档最多64个可见色，256档最多96色；透明为0/255，每边至少宽度1/32留白。
这是具有手绘观感的生成式美术与算法像素化，不宣称逐像素人工绘制。
prompts、references和receipts保存提示词、参考出处、生成job标识、哈希和原目视检查。
官方参考图不作为游戏运行时素材；不能按美术造型反向补写游戏机制。

6. 环境与现成资源检查（无需高分辨率原稿）
使用Python 3.11+，在icons-v6目录执行：
  python3 -m venv .venv
  .venv/bin/python -m pip install -r requirements.txt
Windows使用.venv\Scripts\python.exe；后续python3应替换为安装了依赖的解释器。
  python3 -B scripts/verify_release.py
它检查308个ID、616张PNG、透明/颜色/边距、7图集全部308区域、三个锚点与原资料。
当前公开包缺少308张原始母图是预期状态，会明确记入报告，不计作现成PNG故障。
  python3 -B scripts/build.py
此命令从现成PNG重建manifest、catalog、atlas与联系图，不需要原始母图或图像服务。
联系图字体可用ICON_FONT环境变量指向本机中文字体；字体降级只影响QA联系图文字。
之后再次运行verify_release.py，确认图集区域与现成PNG一致。

7. 仅供持有本机原始归档时使用的历史转换
公开包默认不具备运行下列转换所需的高分辨率源文件。
  python3 -B scripts/rebuild_pngs.py --verify-only --mother-dir path/to/local/icon-mothers
  python3 -B scripts/rebuild_pngs.py --write --mother-dir path/to/local/icon-mothers
--verify-only仅在内存转换并对比两档PNG文件字节和解码像素；--write只接受与冻结清单相同的输出。
也可加--id I001限制到一件。缺原稿时会明确退出，不改用256档冒充原始母图。
  python3 -B scripts/verify_release.py --require-mothers --mother-dir path/to/local/icon-mothers
重新调用图像生成服务不保证得到相同母图；历史可重复性只针对确实持有的原始保存文件。
若导入全新高分辨率源图，可使用process_asset.py；它会将新回执视觉检查重置为pending。
该工具是新增源图导入工具，不是从已交付256像素母版还原旧原稿的工具。

8. 浏览器与按需运行时打包
index.html可直接离线打开。可选自动检查：
  python3 -m pip install playwright
  python3 -m playwright install chromium
  python3 -B scripts/browser_qa.py
已装Chrome时加--browser-channel chrome；脚本自建本机临时HTTP端口测下载，再测file://离线打开。
测试搜索、分类、616张图片解码、下载字节、桌面/手机整数缩放；不提供已移除的原稿预览按钮。
运行时ZIP可按需生成：
  python3 -B scripts/package.py
只在当前dist/生成轻量运行时ZIP，不含高分辨率原图，不写父目录。
公开项目包不必嵌套这份重复ZIP；已保留展开后的全部PNG与图集。

9. 游戏接入
用稳定ID读取runtime/manifest.json的files["256"]或atlas.page/frame。
资源路径相对于icons-v6根，不是runtime/子目录。
使用sRGB、Nearest/Point、Clamp、关闭mipmap；保留占格比例、透明留白和整数显示倍率。
图集原点左上，未裁边未旋转，4px padding，中心锚点(0.5,0.5)。
实际引擎导入、设备UI缩放和玩家辨识仍需接入后验证。
I035名称及sourceFlags中的未知项继续保留；文件验证不等于玩法或审美验收。
