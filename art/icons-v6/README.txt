弹球骑士 · 正式 V6 像素图标交接

308件：175物品、133天赋；616张独立透明PNG；7张256档图集。
两档独立PNG合计7,353,442字节，约7.35MB；图集另19,922,799字节。
本次不改变最终可见像素，不重新生成美术，三件已认可锚点及所有PNG哈希保持不变。
直接打开 index.html 可离线搜索、分类、查看两档尺寸与下载单图。
UI v10与本图标库尚未接入game/的实际界面，接入状态见项目根说明。

308件像素编辑母版
  pixel-master-map.json 直接指向现成 pixels/256/ID.png，没有复制一套图片。
  每件同时记录128/256两档的路径、尺寸、文件大小、文件哈希及像素哈希。
  pixels/256/：宽256；按2×1/2×2/2×3占格高128/256/384。天赋高256。
  pixels/128/：宽128；对应高64/128/192。天赋高128。
  这里128/256是整件画布宽度，对应每个逻辑格64/128像素，不是全部图标都为方形。

公开包不含高分辨率原始母稿，也不再提供原始母稿下载附件。
原先308张、498,562,878字节的高分辨率母图只保留在原电脑的图标工坊源目录，不为交接额外复制一套归档。
现有两档PNG都保留。不能从256档像素母版精确还原原始高分辨率母图，
也不能保证缩小它后精确得到最初独立制作的128档；编辑后的图像需重新检查。

其余文件
  atlas/：256档透明图集与左上原点坐标；不裁边、不旋转，4px padding。
  manifest.json / catalog.js：完整索引。历史mother字段只记录可选本机原稿路径，不代表随包文件。
  runtime/manifest.json / runtime/icons.d.ts：精简接入清单和类型；资源路径相对icons-v6根目录。
  data/briefs.json：原名称、功能、占格、证据与未知项，不按造型补写机制。
  data/approved-anchor-hashes.json：I005、I047、I106三个认可锚点的冻结哈希。
  prompts/ / references/ / receipts/：提示词、参考及出处、生成job与哈希。
  qa/：制作记录和当前公开交接验证；高分辨率重建记录明确标为历史检查。
  scripts/ / requirements.txt：索引、图集、校验、可选原稿转换和按需打包工具。

制作边界
原制作使用内置image_gen逐件参考生成母稿，再按获认可算法等比缩放、限色、二值透明化。
这是生成式手绘观感和算法像素化，不是逐像素人工绘制。
文件与浏览器校验不等同于目标引擎导入或玩家辨识测试。
官方裁图仅保留为视觉参考来源，不属于游戏运行时资源。
I035名称与其他sourceFlags继续保留原始未核实状态。
