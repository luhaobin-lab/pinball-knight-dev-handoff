128/256是整件画布宽度，对应每个逻辑格64/128像素。保留画布比例、透明留白和中心锚点(0.5,0.5)，不要自动裁边或拉伸到方形。使用sRGB、Nearest/Point、Clamp，关闭mipmap。

游戏读取

runtime/manifest.json中的资源路径相对icons-v6资源根。7页图集使用256档；坐标原点左上，不裁边、不旋转，4px透明padding。

const r = manifest.icons.find(x => x.id === "I047");
const imagePath = r.files["256"];
const { page, frame: { x, y, w, h } } = r.atlas;
context.drawImage(atlasImages[page], x, y, w, h, 0, 0, w, h);

编辑与检查

从pixel-master-map.json定位256档后，另存工作副本编辑。两档分别保留与检查。256像素文件不能精确还原原始高分辨率母图，也不保证缩成128后等于原128档。

python3 -B scripts/build.py
python3 -B scripts/verify_release.py

上述索引、图集和PNG检查不需要高分辨率原稿。rebuild_pngs.py只为持有本机原始归档者保留，需显式给出--mother-dir；缺原稿会退出，不能用小像素图冒充原始生成母图。

来源与边界

原制作通过image_gen参考生成透明母图，再算法像素化。提示词、参考出处、生成job与历史检查仍保留。manifest的mother字段与receipts的motherSha256仅用于追溯可选本机原始归档。I035名称及sourceFlags未知项继续保留，不按造型推断规则。UI和图标尚未实际集成；目标引擎导入、设备显示和玩家辨识仍待验证。
