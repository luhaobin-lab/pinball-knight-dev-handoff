手绘像素图标 · 接入说明

返回资源目录

本版使用参考图约束生成母稿，再按已经确认的算法缩放与限色。属于具有手绘观感的生成式美术与算法像素化，不是逐像素人工绘制。本交接包只收录正式 V6；前三件已批准锚点的哈希随包保存。

文件选择

运行时优先使用 pixels/256/ID.png，较小显示可以选 pixels/128/ID.png。这些是带二值透明的索引 PNG；解码为 RGBA 后可交给常见引擎。母稿、提示词和参考图用于再制作，不必打进游戏。

纹理设置

使用 sRGB、Nearest／Point 过滤、Clamp、关闭 mipmap。图标按整数倍率展示，锚点取画布中心 (0.5,0.5)。PNG 已含透明留白，不要再次自动裁边或拉伸到方形。

图集

manifest.json列出每个稳定 ID 的分类、功能、占格、独立文件与图集区域。图集只使用 256 档；每个图集配套 JSON，原点在左上，坐标单位为像素。图标未裁边、未旋转，外留 4px 透明 padding。每边不超过 2048px。

const r = manifest.icons.find(x => x.id === "I047");
// 独立 PNG
const imagePath = r.files["256"];
// 图集读取
const { page, frame: { x, y, w, h } } = r.atlas;
context.drawImage(atlasImages[page], x, y, w, h, 0, 0, w, h);

再制作

mothers/保留原始生成 PNG（Git 克隆后从 Release 的 icon-mothers.zip 单独解压；完整交接 ZIP 已包含）；prompts/保留逐件提示词；receipts/记录生成文件来源、哈希与检查结果。工具调用使用内置 image_gen；逐件生成，不使用代码图形替代母稿。少数最初生成件使用单张已确认母稿作为风格参考，其后使用三件母稿组成的风格板，另附两张官方裁图。

python3 -B scripts/process_asset.py --id I001 --source /path/to/new-mother.png
python3 -B scripts/build.py

需要 Python 3.11+、Pillow 和 numpy；安装版本见 requirements.txt。完整保存母稿的离线重建与跨机步骤见 制作与接入说明。像素化的缩放与限色有损，不能保证重建母稿；同一母稿转换后的像素文件可重复导出。已确认的三个锚点有覆盖保护。

资料与验证边界

完整制作清单中的 sourceMetadata 保留全部来源资料；运行时压缩包的 manifest.json 不包含该字段，保留 name、description、sizeAuthority 和 sourceFlags，分别记录名称、说明、尺寸依据与未知项。I035 的原始名称继续保留未核实标记，不通过美术推断新名称。检查覆盖 PNG 尺寸、透明度、边距、颜色、重复像素、图集区域和浏览器展示；目标引擎导入与玩家辨识仍须在实际游戏中验证。
