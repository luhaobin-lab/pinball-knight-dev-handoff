## 原生PRD批量算法

```text
RollPRDBatch(P,counter,attempts):
    if attempts<=0: return noSuccess,counter
    C=CfromP(P) // finite and>5e-5,clampP<=1;最多80次二分
    if C<=0:return noSuccess,clampInt32(counter+attempts)
    normalize counter below1 by consuming attempts without raw draws
    blockLimit=min(INT_MAX,max(1,ceil(1/sqrt(C))))
    while attemptsRemain:
        block=min(attemptsRemain,blockLimit)
        bound=QuantizedChance(C,counter+block-1)
        skip failures using floor(log(OpenUniform())/log1p(-bound))
        if skip exceeds block:advance counter by block
        else:
            candidateChance=QuantizedChance(C,counterAtCandidate)
            accept if candidateChance>=bound OR OpenUniform()<candidateChance/bound
            success resets counter to1
            rejection advances counter and consumes currentattempt
    return successCount,nextCounter

OpenUniform():
    hi=rawRand15();lo=rawRand15();bit=rawRand15()&1
    return (hi*65536+lo*2+bit+0.5)/2147483648

QuantizedChance(C,n):
    return count{k in[0,32767] where float32(k*float32(1/32767)) < n*C}/32768
```

公共wrapper与数学CfromP的缓存外壳未在数值oracle中完整运行；以上不能用于宣称全部进程行为等价。原生比较已涵盖指定C下的批量算法结果、端点和精确raw消耗。

## 必须沿用的输入/输出约定

- `P`与概率修正是不同单位；品质修正1对应0.01提升量。
- RNG类型、参数传递方式、随机调用求值顺序是函数契约的一部分。
- `Int`溢出、FTrunc、Float/Double转换、数组越界默认值不能用开发语言的默认行为随意代替。
- 按字段存在区分“空数组、空映射、None、0、缺失并继承默认”；不得全部折叠成0。
- `CompositeDataTable`保留父表与覆盖来源；不能将970条合成投影再算作970条独立物理配置。
- 名称含过期/旧的数据需要保留。没有静态引用与自然不可达是两个不同结论。
