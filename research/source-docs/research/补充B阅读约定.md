# 补充B：技能与天赋消费者

打开 `R3补充B_技能与天赋消费者.xlsx`。它在R3数值与机制卷之外，补齐914条配置（662技能＋252天赋）到具体能力、效果、参数读取点和相关函数的关系。

建议按这一顺序查找：

`全部技能消费者总览 → 天赋/技能参数消费映射 → 配置能力效果绑定 → 原参数读取点 → 参数下游表达式 / 数值属主与结果调用 → 已核实消费模式`

每条记录使用原表资产、RowName和稳定ID关联；中文同名不作为唯一标识。全部1,667条配置类引用已解析，3,779个原参数槽保留真实数组长度。

**偏移列的含义**：对于没有独立`@`位置的嵌套字节码节点，表中偏移是其所在原语句／上下文偏移，不一定是嵌套调用操作码的独立字节地址。`source_pointer`始终定位具体的原JSON节点；精确追踪时以完整源文件、JSON指针、函数名和哈希共同定位。

**候选与执行分开**：继承函数表示该类可访问的实现；词法下游使用表示后续出现了相关变量。二者都不自动证明该分支实际运行、变量来自唯一到达定义，或某个动态对象一定是英雄。委托登记也不是立即调用。17项人工核对模式给出已确认的具体消费规则，其他分支保留表达式和未解析说明。

实际调用计数为38,076条调用指令；另有139条BindDelegate和2条InstanceDelegate，合计38,217个带Function字段的节点。两个计数定义不同，不应互相当作漏项。

“完整来源定位JSON”等技术列采用紧凑显示，避免长JSON让每行撑满整个屏幕；内容完整保存在单元格和同名JSON/CSV中。人读规则、属主说明和公式列正常换行。

独立审核验证了全部配置、原始参数、来源指针和类关联，以及关键公共模式。该审核不扩大为全部动态执行路径或所有运行输入下的最终效果证明。
