# 方案与决策历史

本目录用于完整保留后续讨论。它不改变 `game/` 的UI改版前基线。

| 文件 | 状态 |
|---|---|
| `content-reconstruction.json` | 从原用户消息恢复的新游戏内容方向；区别于Abyss原版规格 |
| `方案.md` | 曾批准执行的极简构筑测试室方案；随后UI成果被否定，相关运行代码未随本归档发布 |
| `equipment-audit.json` | 原型选用24件装备的R2与源码对照；完整装备数据请读最新R3 |
| `core-readiness.json` | 当时的实施准备分析；不是原版算法的最终证据 |
| `rejected-hud-*` | 已否定的HUD重设计方案与参考调查，仅作历史记录 |

UI改版之前的历史v1–v4方案位于 `game/` 根目录。最新原包数据位于 `data/` 和 Release研究包，不应与这些新游戏方案混合。
