# TAPTAPGAME · 游戏基线与 Abyss 研究资料

本仓库归档 **2026-10-27 UI 改版之前的最新游戏基线**，以及后续方案、原包研究数据和验证证据。

游戏源码快照：`854cf380b74dd192687a4ee428be46fd6f4acbd7`。其中运行代码与 `beb0cfec73161c2e2e4e01fe43412a7431354149` 完全相同，两者只有工作区说明不同。后来的圣龛 HUD 和双列测试室没有进入本仓库的游戏代码。

## 下载与运行

- [下载归档包、证据包和可玩文件](https://github.com/FilthyFrost/taptapgame-abyss-archive/releases/tag/archive-2026-10-28)
- [可玩单文件入口](play/index.html)：下载后用支持 WebGL2 的浏览器打开；默认进入普通游戏流程，没有强制跳转到调试场景。
- [游戏源码](game/)：Three.js、TypeScript、Vite。需要 Node.js 24 或更新版本。

```sh
cd game
npm ci
npm run dev
```

构建：`npm run build`。类型与测试：`npm run check`。较低并发的完整测试：`npx vitest run --maxWorkers=4`。

这是保留当时行为的原型基线，不是已完成的商业游戏，也不宣称与原版全部行为1:1。浏览器存档保存在该浏览器本地。离线单文件与源码来自同一快照；具体哈希见 [发布来源](docs/provenance/PUBLICATION.json)。

## 数据资料

研究唯一原包基准为 **Ricochet Abyss Demo AppID3910830 / Build25684533**，不是主游戏的其他版本。三卷共115张数据表，含目录共118张工作表。

| 文件 | 用途 |
|---|---|
| [数值与机制](data/Ricochet_Abyss_Demo_R3_01数值与机制.xlsx) | 装备占格、天赋逐级轨迹、怪物经验与成长、宝箱、品质、金币等 |
| [原始字段与证据](data/Ricochet_Abyss_Demo_R3_02原始字段与证据.xlsx) | 原始字段、蓝图函数体、资产与来源索引 |
| [技能与天赋消费者](data/R3补充B_技能与天赋消费者.xlsx) | 662技能、252天赋、3779参数槽与能力/效果读取关系 |
| [全部工作表目录](data/全部工作表目录.csv) | 跨卷查找 |
| [机制文档](docs/research/) | 算法、伪代码说明、成长、原生弹射、消费者与具体未证边界 |

完整机器可读JSON、字节码、伪代码及原生数值证据在 Release 的 `abyss-r3-public-research-evidence.zip` 与补充附件中。公开派生包保留全部已解码研究记录和清单，移除了原包中重复的字体、Engine Slate、ICU、着色器缓存等运行载荷；**没有分发原版安装EXE或完整PAK/UCAS/UTOC**。本地冻结研究包未被改写，公开包包含来源哈希和删选清单。

主要已核验范围：1576条物理配置与970条组合别名、202件修炼物品、252条天赋、42个怪物、5240个蓝图函数；部分随机与成长计算另有当前EXE数值片段的隔离对照证据。

仍未完整证明整会话随机调用交织、全部动态技能路径、Chaos接触/排序/时序，以及部分TLS缓存和CDO虚表链。参数表、静态函数候选和包内存在都不能自动等同于实际执行或可获得。详情见各卷“证据与缺口”和 [研究使用说明](docs/research/08-如何从资料定位到实现.md)。

## 方案的状态

- 游戏目录中的 `方案-v1` 至 `方案-v4` 是历史制作方案，与此游戏基线一起保留。
- [新游戏内容讨论记录](docs/plans/content-reconstruction.json) 描述反弹、装备构筑及长期收益取舍，属于新设计方向，不是原版数据。
- [后续原型方案](docs/plans/方案.md) 和附件仅作讨论/决策历史保留。其后UI实施结果被否定，**不是本仓库的默认游戏版本**。
- `docs/plans/rejected-hud-*` 为已否定的HUD研究历史，不是当前美术基线。

## 归档约定

`game/` 是精确源码快照，保留当时的注释、规格与工具。历史绝对路径仅作来源定位；部分提取工具需要原包和本地工具环境，不能在其他电脑上直接照旧路径执行。原型代码和研究资料中的已知差异不在这次公开归档中擅自修复。

`node_modules`、本机凭据、个人运行目录、完整备份和Git历史数据库不进入仓库。字体等已有许可文件保留；本次归档不额外为第三方材料授予新的许可。

Release提供单文件游戏、完整仓库快照、三卷工作簿及研究证据附件，并附SHA256清单。源码测试结果、公开内容检查与打包来源见 [provenance](docs/provenance/)。
